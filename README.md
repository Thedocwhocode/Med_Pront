# Med_Pront
Adaptação de prontuário eletronico Open_Source - OpenEMR para integração em pequenas clínicas, mantendo robustez e segurança do projeto e adaptando a LGPD brasileira e adequando ao modelo de negócio de pequenas e médias clínicas Brasileiras que desejam ter prontuário auto-hospedado, seguro sem depender de serviços ou assinaturas mensais.
